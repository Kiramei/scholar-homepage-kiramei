# Chengjie Lu — Academic Homepage

Source code for [scholar.kiramei.moe](https://scholar.kiramei.moe), featuring my research profile, publications, research code, and CV.

The site is based on [al-folio](https://github.com/alshedivat/al-folio) and is deployed automatically through GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```
